# Questions, answered with data

Data stories about how Americans shop, by [Suyash Sapre](https://suyashsapre.github.io/). Static site for GitHub Pages; no build step on the host.

Each story folder has `index.html` (the article: one claim, one chart) and `charts.html` (every chart with the full field). Pages are generated by `scripts/build_site.py` in the private analysis repo from licensed ConsumerEdge, SafeGraph, Advan and Consumer Profiles data (via Dewey). Only aggregates are published.
